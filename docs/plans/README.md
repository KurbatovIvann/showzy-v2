# Historical implementation plans

These files are history. New work does not add `docs/plans/<module>.md`
(ADR-0023). Planner output is a Linear feature card and tickets.

Kept here because foundation and Experience Foundation tickets still
point at them:

- `foundation.md` — phase 0/1 task graph (historical)
- `experience-foundation.md` — UX gate workstream
- `v1-mobile-ux-migration.md` — mobile parity roadmap
- `phase-0-audit-remediation.md` — G1 follow-ups
- `spec-process-after-phase-0.md` — superseded by ADR-0023

Do not treat a plan file as a contract. The executable contract of new
work is the feature card plus `*.contract.ts`.
